# Зов Телеситы

**Порядок в музыке. Вечер без суеты.**

Приложение для всех, кто серьёзно относится к своей коллекции:
аргентинский фольклор, танго, милонги, пеньи — или просто любимая
музыка, разложенная по полочкам.

`El Llamado de Telesita`

---

## Кому подходит

**DJ пеньи и милонги.** Готовите вечер неделями — соберите программу
по блокам, расставьте кортины, экспортируйте на флешку. Ведёте вечер —
переключайте треки одним кликом, слушайте следующий в наушниках,
заранее знайте, что и когда играет.

**Танцоры.** Хотите собрать свою музыку для практики, разобрать её
по стилям и оркестрам, сохранить лучшее в избранное — программа
для этого.

**Коллекционеры.** Сотни альбомов, тысячи треков, разложенных по
папкам вручную — приложение приведёт это в порядок: распознает типы
танцев, проставит метаданные, сгруппирует по любому полю.

**Любители аргентинской музыки.** Танго, вальс, милонга, чакарера,
самба, гуарания — программа знает все жанры и умеет искать по ним.
Независимо от того, играете вы на вечере или слушаете дома.

---

## Что это даёт

**Музыка наконец организована.** Одна библиотека, все треки в одном
месте. Секции для фольклора и танго, каждая со своей логикой
раскладки. Группировка по любому полю: тип танца, оркестр, стиль,
десятилетие, певец. Поиск, фильтры, рейтинг.

**Программу вечера видно на ладони.** Блочный плейлист — не список
файлов, а структура: танда за тандой, кортина между ними, длительность,
энергия, средний BPM. Сразу видно, что уже набрано, чего не хватает,
где музыка провисает.

**Вечер идёт без суеты.** Очередь воспроизведения, preview в наушниках
(пока играет на колонки — слушаете следующий трек), метки-выкрики,
горячие клавиши.

**Программа переносится на флешку.** Экспорт в папку: файлы
переименовываются по шаблону, теги записываются правильно. Любой плеер
(даже на телефоне) покажет треки в нужном порядке — просто откройте
папку.

**Всё остаётся у вас.** Никаких облаков, подписок, регистраций.
Программа работает полностью локально. Ваша музыка — только ваша.

## Возможности

### Библиотека

- **Секции:** фольклор и танго независимо.
- **Группировка:** по типу танца, оркестру, стилю, году, певцу.
- **Сканирование папок:** тип танца определяется из имени подпапки.
- **Теги:** title, artist, album, комментарии — редактируются вручную
  и массово.
- **Рейтинг 1–10.** Чтобы отмечать любимое.

### Плейлист

- **Блоки** с перетаскиванием: между блоками и внутри блоков.
- **Служебные блоки «Начало» и «Завершение»** — границы рабочей зоны.
  Всё, что вне их, не учитывается в статистике и экспорте.
- **Кортины:** пауза, конкретный трек, случайная из пула, случайная
  из группы.
- **Проверка повторов** в плейлисте.
- **Мультиплейлисты** <span title="Требуется Pro">💎</span>.

### Воспроизведение

- **Два независимых потока:** основной в колонки, preview в наушники.
- **Очередь** с drag&drop, случайным порядком, повтором.
- **VLC** под капотом — без заиканий при выключении экрана.
- **MP3, FLAC, WAV.**

### Экспорт

- **Копирование в папку** с правильными именами и тегами.
- **Свой шаблон** для фольклора и для танго.
- **HTML** — распечатать или открыть в браузере.
- **PDF** — с цветами активной темы.

### Оформление

- **Встроенные темы:** Mocha, Midnight, Slate.
- **Свои темы:** подключите JSON с палитрой.
- **Размер шрифта** треков.

## Pro

Часть функций активируется лицензионным ключом. Ключ выдаётся автором
на 30, 60 или 90 суток, проверяется офлайн. Никаких звонков на сервер
при запуске.

В Pro входит:

- **Мультиплейлисты** — несколько независимых плейлистов.
- **Группы кортин** — разбивка кортин по настроению: «Быстрые»,
  «Романтичные», «Классика 40-х». Один трек может быть сразу
  в нескольких группах. В блоке — «случайная из группы X».

Активация: **Инструменты → Активировать Pro…**

## Системные требования

- Windows 10 или новее (64-bit)
- Свободное место на диске под музыку

VLC и всё остальное уже внутри. Установка VLC или Python не требуется.

---

## Установка

1. Скачайте `ZovTelesity.exe` со страницы релизов.
2. Запустите. Установка не нужна.
3. При первом запуске укажите корневую папку с музыкой.
4. Пользуйтесь.

---

## Быстрый старт

**Фольклор.** Разложите музыку по папкам, чьи имена соответствуют
типам танцев:
📁 D:\Музыка для пеньи
📁 Chacarera simple 8
📁 Chacarera doble 6
📁 Zamba argentina
📁 Gato
📁 Chamamé

Меню **Файл → Сканировать папку…** — тип танца установится
автоматически.

**Танго.** В настройках библиотеки выберите ось раскладки: по
оркестрам, по стилю, по десятилетиям или плоско.

**Вечер.** Соберите плейлист из блоков. Перед выступлением —
**«📂 Копировать в папку…»**.

---

## Почему «Зов Телеситы»

Телесита — персонаж аргентинского фольклора, девочка-сирота из
Сантьяго-дель-Эстеро, которую почитают как народную святую. Ей
ставят свечи, ей посвящают песни, а Чакареру танцуют «для Телеситы».

Полная легенда — в приложении, в меню «Справка».
