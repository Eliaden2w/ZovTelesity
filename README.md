# Зов Телеситы

Десктопное приложение для подготовки и ведения музыкальных вечеров —
пеньи и милонги. Собирает библиотеку, помогает составить блочный
плейлист, ведёт вечер и экспортирует программу на флешку с правильными
именами файлов и тегами.

`El Llamado de Telesita`

## Для кого это

Для DJ, который ведёт пенью или милонгу: готовит программу заранее,
знает, что и в каком порядке будет играть, ведёт вечер без суеты и хочет,
чтобы всё работало предсказуемо.

Программа одинаково подходит и для того, чтобы просто разложить музыку
по полочкам — по типам танцев, оркестрам, стилям, годам, — без всякой
привязки к конкретному выступлению.

## Что умеет

**Библиотека.** Все треки в одном месте. Группировка по типу танца
(фольклор) или по оркестру / стилю / десятилетию / певцу (танго).
Поиск, фильтры, метаданные из файлов: исполнитель, название, BPM,
длительность, битрейт. Рейтинг 1–10 — чтобы отмечать любимое.

**Секции.** Фольклор и танго живут рядом, но независимо. У каждой
секции своя корневая папка и своя логика раскладки файлов на диске.
Переключаются одним кликом.

**Избранное.** Рабочий пул треков для быстрого доступа. Черновой отбор
перед распределением по блокам плейлиста.

**Блочный плейлист.** Пенья и милонга — это не сплошной список треков,
а структура. Блоки «Начало» и «Завершение» задают рабочую зону; всё
между ними идёт в статистику, визуализацию и экспорт. Блоки
перетаскиваются, треки — внутри блока и между блоками.

**Кортины.** Между блоками — пауза, конкретный трек, случайная из
пула или случайная из группы по настроению. Случайные не повторяются,
пока пул не исчерпан. Для милонги последовательность кортин
настраивается для каждого блока.

**Прослушивание в наушниках.** Пока основной трек играет на колонки,
вы слушаете следующий через наушники. Как у профессиональных DJ-плееров:
две независимые очереди, два независимых устройства вывода.

**Визуализация.** Энергетический профиль сета по блокам. Для фольклора —
распределение по типам танцев. Для танго — по оркестрам и стилям.
Сводка по количеству треков, длительности, среднему BPM.

**Экспорт.** Копирование плейлиста в папку с переименованием файлов и
записью тегов, чтобы любой плеер (даже на телефоне) показывал треки
в нужном порядке.

- Фольклор: `[блок].[трек].[танец].[исполнитель].[название].mp3`
- Милонга: `[NN][t/v/m]. [позиция][k?]. [оркестр] - [название].mp3`
  (`k` — кортина, `t/v/m` — tango / vals / milonga)
- Экспорт в HTML — распечатать или открыть в браузере
- Экспорт в PDF — с цветами активной темы

**Проверка повторов.** Ищет треки с одинаковым нормализованным названием,
игнорируя регистр, `(feat. …)`, `[Remastered]`, «01. » и пунктуацию.

**Темы оформления.** Встроенные палитры (Mocha, Midnight, Slate), плюс
можно добавлять свои.

## Pro-версия

Часть функций активируется лицензионным ключом. Ключ выдаётся автором
на 30, 60 или 90 суток, проверяется офлайн — приложение не обращается
к серверу при запуске.

В Pro входит:

- **Мультиплейлисты** — несколько независимых плейлистов, между которыми
  можно переключаться.
- **Группы кортин** — разбивка кортин по настроению: «Быстрые»,
  «Романтичные», «Классика 40-х». Один трек может быть в нескольких
  группах. В блоке можно поставить «случайная из группы X» — кортины
  будут чередоваться по характеру.

Активация: **Инструменты → Активировать Pro…**

## Чего нет и не будет

- Не заменяет Rekordbox, Serato, Traktor. У нас нет битматчинга,
  скретча, эффектов. Мы играем целые треки, а не миксуем.
- Не требует интернета. Работает полностью локально.
- Не хранит вашу музыку на своём сервере. Всё остаётся у вас.

## Системные требования

- Windows 10 или новее (64-bit)
- Свободное место на диске под вашу музыку

VLC и все зависимости идут в комплекте. Отдельная установка VLC или
Python не требуется.

## Установка

1. Скачать последнюю версию `ZovTelesity.exe` со страницы релизов.
2. Запустить. Установка не нужна.
3. При первом запуске выбрать корневую папку для музыкальной библиотеки.
4. Пользоваться.
