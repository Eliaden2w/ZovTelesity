# Peña Planner

**Peña Planner** — настольное приложение для подготовки и проведения музыкальных вечеров (пенья). Помогает управлять библиотекой треков, составлять блочные плейлисты, контролировать длительность и порядок номеров, а также воспроизводить музыку с высоким качеством звука.

## Возможности

- **Библиотека треков**  
  Храните все аудиофайлы в одном месте. Группируйте их по типу танца, редактируйте теги, рейтинг и BPM.

- **Избранное**  
  Отбирайте треки в отдельный список для быстрого доступа.

- **Блочный плейлист**  
  Создавайте блоки (например, «Чакареры», «Замбы»), наполняйте их треками, перетаскивайте блоки и треки мышью. Служебные блоки «Начало» и «Завершение» создаются автоматически и защищены от удаления и переименования.

- **Визуализация**  
  Энергетический профиль, распределение танцев, сводка по длительности и BPM.

- **Экспорт в папку**  
  Копируйте плейлист в отдельную папку с понятными именами файлов и правильными тегами (Title, Artist, Album, Track number, Disc number).

- **Качественный звук**  
  Воспроизведение через VLC (WASAPI), без заиканий при выключении экрана. Поддержка MP3, FLAC, WAV.

- **Автоматическое обновление**  
  Приложение проверяет наличие новых версий на GitHub Releases и предлагает скачать обновление.

## Установка

1. Скачайте последнюю версию `PenaPlanner.exe` из раздела [Releases](https://github.com/your_username/PenaPlanner/releases).
2. Запустите файл. Установка не требуется.
3. Начните добавлять музыку: нажмите «Сканировать папку» и укажите корневую папку с треками.

> **Примечание:** VLC уже встроен в исполняемый файл. Отдельная установка VLC или Python не требуется.

## Использование

### Подготовка библиотеки
Рекомендуется разложить музыку по папкам, имена которых соответствуют типам танцев:

D:\Музыка для пеньи
Chacarera simple 8
Chacarera doble 6
Zamba argentina
Gato
...

При сканировании такой папки тип танца будет определён автоматически по имени подпапки.

### Создание плейлиста
1. Перейдите на вкладку «Плейлист».
2. Блоки «Начало» и «Завершение» уже созданы. Добавляйте свои блоки между ними (кнопка «+ Блок»).
3. Перетаскивайте треки из библиотеки или избранного в нужные блоки.
4. Меняйте порядок блоков и треков перетаскиванием.
5. Следите за общей длительностью и средним BPM в шапках блоков.

### Экспорт
Когда плейлист готов, нажмите «📂 Копировать в папку…» и выберите директорию. Файлы будут скопированы с именами вида:

Chacarera simple 8. 03. Chacarera simple 8 - Facundo Toro - Tu Llegada.mp3

Теги будут заполнены соответствующим образом.

### Обновление
При запуске приложение проверяет наличие новой версии на GitHub. Если доступна новая версия, появится диалог с кнопкой «Скачать», которая откроет страницу загрузки.
